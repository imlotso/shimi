# 今晚有谱

面向上班族的微信小程序第一版：选食材、推荐菜谱、搜索菜名、查看详细步骤，并提供简单减脂轻食推荐。

## 当前功能

- 首页：搜索入口、常用食材快捷选择、今晚推荐、减脂入口。
- 选食材：支持分类、搜索、已选食材管理，不限制选择数量。
- 智能推荐：按已选食材评分排序，展示命中食材和还需补充的主食材。
- 菜谱详情：时间、难度、热量估计、蛋白质估计、食材清单和新手步骤。
- 菜谱库：按关键词和快手/减脂/高蛋白/新手筛选。
- 减脂轻食：低油、高蛋白、轻晚餐筛选，以及 5 天轻食安排。
- 我的：本地收藏、最近浏览记录和匿名意见反馈。

## 意见反馈配置

页面入口在“我的”页，用户只需要填写反馈内容，不需要留下手机号、微信号或其他个人信息。

反馈提交到云函数 `submitFeedback`，默认写入云数据库集合 `feedbacks`。上线前需要：

1. 在微信开发者工具里开通云开发。
2. 创建或选择一个云环境。
3. 右键 `cloudfunctions/submitFeedback`，选择“上传并部署：云端安装依赖”。
4. 在云开发控制台创建数据库集合 `feedbacks`，权限建议设为“仅创建者及管理员可读写”或使用云函数写入。

如果希望同步发送邮件，在云函数环境变量里配置：

- `FEEDBACK_SMTP_HOST`：SMTP 服务器地址。
- `FEEDBACK_SMTP_PORT`：SMTP 端口，常见为 `465`。
- `FEEDBACK_SMTP_USER`：发件邮箱。
- `FEEDBACK_SMTP_PASS`：邮箱 SMTP 授权码，不是登录密码。
- `FEEDBACK_MAIL_TO`：接收反馈的邮箱。

## 内容与图片

- 当前内置 22 个常见食材、24 道常见菜谱。
- 菜谱做法选择了家常、步骤稳定、适合新手执行的版本。
- 热量和蛋白质为单人份估计，实际会随食材大小、用油量和调料变化。
- 食材图、菜品图和导航图标均为本地生成的 2D 插画资源。

## 打开方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择文件夹
4. AppID 暂时使用 `touristappid`，真实上线前需要替换为你的微信小程序 AppID。

## 资源生成

当前菜品图和食材图已改为 `image_gen` 生成的半拟真 JPG 资源。旧的几何 PNG 生成脚本已弃用，不要再运行 `scripts/generate-assets.ps1`。

为了通过微信小程序自动预览的 2MB 限制，包内图片已压缩为：

- 菜品图：`600 x 400` JPG
- 食材图：`256 x 256` JPG

如新增图片后包体变大，可运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\optimize-assets.ps1
```
