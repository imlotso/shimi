# 云函数说明

分支前缀：`feature/cf-xxx`

## 现有云函数

- `submitFeedback`：提交反馈写入 `feedbacks` 集合，可选配置 SMTP 环境变量同步发邮件（见仓库 README）。

## 待新建云函数（对应规划书核心闭环）

- `matchDishes`：食材+厨具反向匹配，顺序为 先查 auditStatus=1 → 厨具严格过滤（全部覆盖才命中）→ 食材宽松匹配（主要食材覆盖即命中，调料不参与）。
- `recommendByTaboo`：忌口排除式过滤，`taboos` 与用户勾选有交集就排除，严格执行不许例外。
- `submitDish`：投稿写入 `dishes`，`auditStatus` 默认 0，只允许本人 openid 编辑/删除自己的投稿。
- `auditDish`：审核通过/驳回，只有白名单 openid 能调用，同时写 `audit_log`。
- `matchDishes`：接收 `selectedIngredientIds`、`selectedToolIds`、`selectedTabooIds` 三个字符串数组（也兼容 `ingredients`、`tools`、`taboos` 别名），只查询 `auditStatus=1` 的菜品。主要食材由数据库 `ingredients` 中文名排除调料后推导（若有 `mainIngredientIds` 则优先用 ID 映射），全部覆盖才命中；厨具要求全部覆盖，数据库与入参均建议使用中文名（例如 `炒锅`），代码同时兼容 ID 和中文名；忌口有交集则排除。返回 `{ ok: true, data: [...] }`。
- `getDishDetail`：接收 `{ dishId }`；已发布菜品、当前用户本人投稿、或 `ADMIN_OPENIDS` 环境变量白名单中的管理员可查看。成功返回 `{ ok: true, data: dish }`，无权或不存在返回 `{ ok: false, code: "DISH_NOT_FOUND" }`。
- `manageCollect`：接收 `action` 为 `add`、`remove`、`check`、`list`；openid 始终由 `cloud.getWXContext().OPENID` 获取，前端传入的 openid 不参与鉴权。

## 开发约定

- 管理员 openid 白名单写在云函数代码/环境变量里，不要写死在前端。
- 每个云函数只做一件事，不要把匹配+审核写到同一个函数里。
- 改了云函数返回字段结构，必须同步告知前端角色。

## 本地规则测试

仓库提供 `scripts/test-cloudfunctions.js`，不连接云环境即可验证匹配和详情可见性规则：

```bash
node scripts/test-cloudfunctions.js
```

`matchDishes` 调用示例：

```json
{
  "selectedIngredientIds": ["tomato", "egg"],
  "selectedToolIds": ["wok"],
  "selectedTabooIds": []
}
```

成功返回示例：

```json
{
  "ok": true,
  "data": [{ "_id": "dish-001", "name": "番茄炒蛋", "mainIngredientIds": ["tomato", "egg"] }]
}
```

`getDishDetail` 调用示例：

```json
{ "dishId": "dish-001" }
```

无权查看时返回：

```json
{ "ok": false, "code": "DISH_NOT_FOUND", "message": "菜品不存在或无权查看" }
```

管理员白名单通过云函数环境变量 `ADMIN_OPENIDS` 配置，多个 openid 使用英文逗号分隔，不提交到代码仓库。

## manageCollect 接口

`collect` 集合使用 `{ openid, dishId }` 字段。`openid` 不由前端传入，云函数从微信上下文获取。

新增收藏：

```json
{ "action": "add", "dishId": "tomato-egg" }
```

首次成功返回：

```json
{ "ok": true, "data": { "isCollected": true, "created": true, "collectId": "collect-id" } }
```

重复新增是幂等操作：

```json
{ "ok": true, "data": { "isCollected": true, "created": false } }
```

取消收藏：

```json
{ "action": "remove", "dishId": "tomato-egg" }
```

查询单个收藏：

```json
{ "action": "check", "dishId": "tomato-egg" }
```

```json
{ "ok": true, "data": { "isCollected": false } }
```

查询当前用户收藏列表：

```json
{ "action": "list" }
```

列表只返回当前用户收藏且仍已发布的菜品卡片：

```json
{ "ok": true, "data": [{ "_id": "tomato-egg", "name": "番茄炒蛋", "cover": "", "totalTime": 12, "tags": [], "collectId": "collect-id" }] }
```

不存在或未发布菜品不能新增收藏，返回 `DISH_NOT_FOUND`；remove、check、list 始终按服务端 openid 隔离用户数据。

## matchDishes 纯忌口模式

当 `selectedIngredientIds` 和 `selectedToolIds` 都为空时，函数不执行食材和厨具限制，只查询已发布菜品并执行忌口排除：

```json
{
  "selectedIngredientIds": [],
  "selectedToolIds": [],
  "selectedTabooIds": ["花生"]
}
```
