# 云函数说明

分支前缀：`feature/cf-xxx`

## 现有云函数

- `submitFeedback`：提交反馈写入 `feedbacks` 集合，可选配置 SMTP 环境变量同步发邮件（见仓库 README）。

## 待新建云函数（对应规划书核心闭环）

- `matchDishes`：食材+厨具反向匹配，顺序为 先查 auditStatus=1 → 厨具严格过滤（全部覆盖才命中）→ 食材宽松匹配（主要食材覆盖即命中，调料不参与）。
- `recommendByTaboo`：忌口排除式过滤，`taboos` 与用户勾选有交集就排除，严格执行不许例外。
- `submitDish`：投稿写入 `dishes`，`auditStatus` 默认 0，只允许本人 openid 编辑/删除自己的投稿。
- `auditDish`：审核通过/驳回，只有白名单 openid 能调用，同时写 `audit_log`。

## 开发约定

- 管理员 openid 白名单写在云函数代码/环境变量里，不要写死在前端。
- 每个云函数只做一件事，不要把匹配+审核写到同一个函数里。
- 改了云函数返回字段结构，必须同步告知前端角色。
