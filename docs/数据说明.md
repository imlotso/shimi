## 字段字典与本次导入说明

### `dishes`

每条菜谱文档使用以下 V1 字段：

- `_id`：沿用本地菜谱 `id`，用于重复导入时幂等定位。
- `name`：菜谱名称。
- `cover`：封面图片地址。
- `totalTime`：预计总耗时，正整数，单位为分钟。
- `tags`：菜谱标签数组。
- `ingredients`：食材数组，每项为 `{ name, num }`，其中 `num` 保留原始用量描述。
- `tools`：完成菜谱所需厨具数组，要求匹配时全部覆盖。
- `taboos`：忌口数组；与用户忌口有交集时排除。
- `steps`：步骤数组，每项为 `{ desc, time }`，`time` 为正整数分钟。
- `openid`：数据所属用户标识；系统种子数据使用 `__seed_system__`。
- `auditStatus`：审核状态，`0` 待审核、`1` 已发布、`2` 已驳回。本次种子数据为 `1`。
- `rejectReason`：驳回原因，仅驳回数据使用。

V1 不启用 `difficulty`、`season`、`stepImgs` 等预留字段。

### 字典集合

- `ingredients`：`{ name, category }`，本次导入 99 条。
- `tools`：`{ name }`，本次导入 11 条。

### 导入流程

在项目根目录执行：

```bash
node scripts/seed-dishes.js --export-json
node scripts/validate-ci.js
```

脚本会生成 `scripts/.generated/` 下的三个 JSON Lines 文件，每行一条完整 JSON 文档，分别导入云开发控制台的 `dishes`、`ingredients`、`tools` 集合。数组格式 JSON 不符合控制台导入要求。生成目录已加入 `.gitignore`，不提交生成文件。
